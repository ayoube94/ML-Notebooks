# ML-Notebooks

## Descripción

Repositorio que almacena notebooks con mi progreso en Machine Learning. Documentando el aprendizaje y experimentación con diferentes técnicas, modelos y frameworks de ML.

## Autor

Ayoub El Hassouni

## Propósito

Este proyecto sirve como portafolio y registro del progreso en el desarrollo de habilidades de Machine Learning, incluyendo:

- Análisis exploratorio de datos
- Preprocesamiento y limpieza de datos
- Entrenamiento y evaluación de modelos
- Experimentación con diferentes algoritmos
- Visualización de resultados

## Contenido

Los notebooks están organizados por temas y modelos específicos. Cada notebook contiene explicaciones, código comentado y resultados de los experimentos.

## Tecnologías

- Python
- Jupyter Notebooks
- Scikit-learn
- Pandas
- NumPy
- Matplotlib / Seaborn
